# Learner Profile

## Background

- Internet industry algorithm engineer.
- Current work: algorithm services for internal marketing activity evaluation.
- Familiar business areas: LTV/GTV prediction, PSM/DML/ITE causal inference, membership system evaluation, marketing campaign analysis.

## Learning Goal

Become a practical LLM application / Agent engineer who can design, build, evaluate, and optimize useful business Agents.

## Teaching Preference

- Teach from shallow to deep.
- Keep high information density and high transfer value.
- Avoid jargon stacking without explanation.
- Connect new AI concepts back to algorithm engineering and marketing evaluation.

## Scope Decision

Causal inference is an existing strength. The learning plan should not re-teach PSM/DML/ITE as the main topic. Instead, it should teach how to turn those methods into safe, diagnosable, testable Agent tools.
