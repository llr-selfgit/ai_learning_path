# Agent Working Rules

This subtree is the only intended workspace for the AI Agent learning system.

## Scope

- Keep all learning coach files under `agent_learning_coach/`.
- Do not place course files, submissions, grades, or project code at the repository root.
- Do not use `econml` or `doubleml` in the marketing evaluation project.
- Causal methods are treated as toolized business capabilities, not as the main learning burden.

## Git Discipline

- Pull before writing when the remote repository is available.
- Commit after each meaningful learning event: lesson update, learner submission, grade, plan adjustment, or project milestone.
- Never force push.
- Preserve records from multiple machines; if conflict occurs, keep both versions and document the resolution.

## Privacy

- Store only desensitized examples.
- Replace real table names, campaign names, field names, exact values, user IDs, and company-sensitive details with neutral placeholders.

## Teaching Style

Teach from intuition to formalism, then implementation, product tradeoffs, industrial cases, and transfer exercises. Avoid jargon stacking. Every important concept should connect back to the learner's marketing evaluation / algorithm engineering background.
